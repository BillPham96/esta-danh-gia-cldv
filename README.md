# ESTA — Đánh giá CLDV & Chế tài nhà thầu

Web lập biên bản vi phạm, tổng hợp khấu trừ phí dịch vụ tháng, thông báo nhà thầu (PDF + nội dung email) và dashboard tái phạm cho dịch vụ An ninh – Vệ sinh tại L'MAK 68, Lite The Venture, 127 Hồng Hà, 130 Hồng Hà.

- Chạy hoàn toàn trên trình duyệt (GitHub Pages), không cần máy chủ. Dữ liệu lưu trong trình duyệt của từng máy — dùng nút **Dữ liệu** để xuất/nhập file sao lưu.
- Tài khoản: danh sách `ACCOUNTS` trong `index.html` (chỉ để phân vai trò, không phải bảo mật).
- Danh mục lỗi & mức phạt trích từ hợp đồng; Quản lý vận hành chỉnh sửa trong mục **Hợp đồng**.
