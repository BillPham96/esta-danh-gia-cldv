# ESTA — Đánh giá CLDV & Chế tài nhà thầu

Web lập biên bản vi phạm, tổng hợp khấu trừ phí dịch vụ tháng, thông báo nhà thầu (PDF + nội dung email) và dashboard tái phạm cho dịch vụ An ninh – Vệ sinh tại L'MAK 68, Lite The Venture, 127 Hồng Hà, 130 Hồng Hà.

- Chạy hoàn toàn trên trình duyệt (GitHub Pages), không cần máy chủ. Đây là bản demo: các tài khoản dùng chung dữ liệu trong trình duyệt trên cùng máy; chưa đồng bộ giữa nhiều máy. Dùng nút **Dữ liệu** để xuất/nhập file sao lưu.
- Luồng biên bản: tài khoản dự án lưu nháp hoặc gửi admin duyệt; admin có thể chỉnh sửa, duyệt chính thức hoặc từ chối kèm lý do. Chỉ biên bản đã duyệt mới được tính vào báo cáo và khấu trừ.
- Tài khoản mẫu trong `index.html` chỉ để trình diễn phân vai trò, không phải xác thực bảo mật. Cần tích hợp backend và đăng nhập thật trước khi dùng trên nhiều máy hoặc với dữ liệu thực tế.
- Danh mục lỗi & mức phạt trích từ hợp đồng; Quản lý vận hành chỉnh sửa trong mục **Hợp đồng**.
